# НСИ — устав проекта для людей и агентов

**Прочитай этот файл в начале любой сессии по этому репозиторию.** Это отдельный продукт, не продолжение и не форк логики чужих задач.

## 1. Что это

**НСИ** — сервис учёта и нормализации **номенклатуры** для сотрудника (ввод и правка карточек, подсказки, предупреждения о дублях, габариты и вес, ТН ВЭД, НДС, привязка к группам из выгрузки 1С).

- **UI:** Streamlit (`app.py`), без отдельного фронтенда.
- **Данные:** SQLite `data/nsi.db` по умолчанию; позже PostgreSQL через `NSI_DATABASE_URL` (тот же SQLAlchemy).
- **Справочник 1С:** ручная загрузка **полного или частичного** каталога из **Excel** в таблицу `onec_catalog_entries` (`services/onec_excel.py`, вкладка в UI). По наименованию подбираются строки для подсказки **группы / ТН ВЭД / НДС** (не юридически гарантированно — проверка человеком).
- **Интеграция 1С в реальном времени:** только через абстракцию `integrations/onec_client.py` (сейчас `LocalOneCClient` = та же БД). HTTP к 1С — новая реализация того же контракта.

## 2. Жёсткие границы

1. **Этот репозиторий — только НСИ.** Код в корне этого репо (`nsi`).
2. **Не трогать проект `pim`** (соседний репозиторий/папка): не менять файлы внутри `pim`, не импортировать `pim` как пакет.
3. **Не расползать в сторону маркетплейсов** (Ozon/WB и т.д.), если это не запрошено отдельным ТЗ для НСИ. Парсинг **сайта поставщика** здесь ограничен **габаритами, весом и при необходимости ТН ВЭД** для карточки номенклатуры (`services/supplier_parsers/`), не для маркетинговых обогащений.

## 3. Настройка ТН ВЭД / НДС (РФ)

- **Файл правил:** `data/tnved_vat_ru.json` (или путь в `NSI_TNVED_VAT_CONFIG`): страна `RU`, `default_vat_percent`, список двузначных префиксов для 10%, точные коды `exact_code_vat_percent`, доп. префиксы `prefix_vat_percent`.
- **Опционально HTTP:** переменная `NSI_TNVED_VAT_LOOKUP_URL` — шаблон URL с `{code}` (например `https://api.example.com/tnved?code={code}`). Ожидается JSON с полем `vat_percent` / `vat` / `nds` / `VAT`. При ошибке сети используется файл.
- После правки JSON в сайдбаре Streamlit: **«Обновить правила НДС»** (сброс кэша) или перезапуск приложения.

## 4. Парсеры сайта поставщика

- **Карта домен → парсер:** `data/supplier_sites.json` (`hosts`: `"домен": "id_парсера"`, `default_parser`).
- **Реализации:** `services/supplier_parsers/generic.py` (`id = generic`) и при необходимости `services/supplier_parsers/sites/<id>.py` с классом **`Parser`** и методом `parse(html, url)`.
- В форме занесения: URL карточки товара → кнопка загрузки; в каталоге сохраняется `supplier_parser_id`.
- После правки JSON: **«Обновить парсеры»** в сайдбаре.

## 5. Единицы и расчёты (канон)

| Величина | Хранение | Примечание |
|----------|----------|------------|
| Длина, ширина, высота | **мм** | Ввод в других единицах — через пересчёт (`services/units.py`). |
| Вес | **кг** | г, lb → кг. |
| Объём | **м³** | `L×W×H` в мм → м³ (`services/dimensions_service.py`), сохраняется в `volume_m3`. |
| ТН ВЭД | строка цифр | нормализация в `services/tnved_vat.py`. |
| НДС | % | 0 / 10 / 20 или ручной ввод; **эвристика по ТН ВЭД** — подсказка, не налоговая консультация. |

**Статистика:** медиана габаритов по другим позициям в **той же группе НСИ** (`services/stats_dimensions.py`), минимум три заполненные позиции.

## 6. Бизнес-правила (не ломать без согласования)

| Правило | Где |
|--------|-----|
| Артикул не может быть **только цифрами**; подсказка `ТСР-NNNNN` | `services/nomenclature.py` |
| Наименование **≤ 100** символов | `config.NAME_MAX_LEN`, UI |
| Дубли по имени: предупреждение, порог | `services/duplicates.py`, `config.DUPLICATE_SIMILARITY_THRESHOLD` |
| Штрихкод: цепочка поставщик → автопоиск → ГС1 (часть заглушек) | `services/barcode_flow.py` |
| Импорт Excel 1С: гибкие заголовки | `services/onec_excel.py` |
| Группа из пути 1С: последний сегмент пути → `NsiGroup` | `services/groups_onec.py` |
| НДС по ТН ВЭД (РФ): JSON + опц. URL | `services/tnved_vat.py`, `data/tnved_vat_ru.json` |
| Парсер поставщика по домену | `services/supplier_parsers/`, `data/supplier_sites.json` |

## 8. Что считать «готово» для следующего шага

- Пользователь может создать позицию, увидеть каталог и кандидатов дублей.
- Правила ТН ВЭД/НДС настраиваются JSON (и при необходимости URL) без правки кода.
- Парсер поставщика выбирается по домену URL карточки; при необходимости добавляется модуль в `supplier_parsers/sites/`.
