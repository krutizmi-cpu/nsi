# НСИ — сервис номенклатуры

Отдельный проект (не связан с репозиторием `pim`). Интерфейс на **Streamlit**, данные в **SQLite** (`data/nsi.db`), позже — **PostgreSQL** через переменную `NSI_DATABASE_URL`.

**Обязательно к прочтению для разработки и для ИИ-агентов:** [AGENTS.md](AGENTS.md) — устав проекта и границы (в т.ч. «не трогать PIM»).

## Быстрый старт

```bash
cd nsi
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

## Что уже есть

- форма новой позиции: артикул (валидация «только цифры» — нельзя), подсказка следующего кода `ТСР-NNNNN`, наименование с лимитом 100 символов;
- **габариты (мм), вес (кг), объём (м³)**; пересчёт из см/м/дюймов и г/lb; загрузка с **URL поставщика** (эвристический разбор HTML);
- **медиана габаритов по группе** (если в группе ≥3 заполненных позиций);
- **ТН ВЭД**, подсказка **НДС** по упрощённой эвристике (проверка человеком обязательна);
- **импорт справочника 1С из Excel** и подсказка группы/ТН ВЭД/НДС по похожести наименования;
- **массовая загрузка из Excel**: загрузка файла с колонками `supplier_article`, `name`, `supplier_name`, `supplier_url` (обязательно), `barcode`, `length_mm`, `width_mm`, `height_mm`, `weight_kg` (необязательно); автоматический парсинг страниц поставщиков, определение категории, создание позиций;
- группы (минимум: «Без группы»), маркировка, цепочка штрихкода (`services/barcode_flow.py`);
- кандидаты дублей (`rapidfuzz`, порог в `config.py`);
- заглушка `integrations/onec_client.LocalOneCClient` — чтение/запись той же БД; HTTP к 1С — отдельной реализацией `OneCClient`.

## Новый репозиторий Git

Каталог `nsi` лежит рядом с `pim`. Инициализация репозитория только здесь:

```bash
cd nsi
git init
git add .
git commit -m "Initial commit: НСИ scaffold"
```

## Развёртывание на своём сервере

- задать `NSI_DATABASE_URL` для PostgreSQL при необходимости;
- запуск: `streamlit run app.py` за reverse proxy (nginx/Caddy) с HTTPS.
